## 🚀 Features

* 🎤 Reconnaissance vocale avancée (Whisper)
* 🗣️ Synthèse vocale réaliste (Edge TTS)
* 🖥️ Contrôle complet du système
* 📱 Lancement d’applications
* 🌐 Navigation web automatisée
* 🎬 Mode cinéma immersif
* 🖥️ Support multi-écrans
* 🔊 Contrôle multimédia
* ⚡ Monitoring CPU / RAM
* 😴 Mise en veille automatique + réveil sonore

---

## 🧠 Tech Stack

* OpenAI Whisper
* Microsoft Edge TTS
* Python (async, threading)
* PyAutoGUI / PSUtil / SoundDevice
